## Article

Let $`\Delta X`$ denote the space of
probability measures on a metric space $`X`$
(and using the Borel-$`\sigma`$-algebra).

The sets $`A`$ and $`O`$ are finite sets of
actions and observations.

We will use the notions of 
histories, destinies, policies, and environments as in IB_RL.md.
The space of policies is denoted by $`\Pi`$.
Also, we will use $`\mu^\pi \in \Delta(A\times O)^\omega`$
for the probability distribution on destinies
induced by a policy $`\pi`$ and an environment $`\mu`$.

**Lemma (metric of weak convergence)**:
Let $`X`$ be a compact metric space.
Then $`\Delta X`$ can be endowed with a metric $`d`$
with the following convergence property:
A sequence of probability measures
$`\{\mu_n\}_{n\in\mathbb{N}}`$
converges with respect to $`d`$ to a probability measure $`\bar\mu`$ 
if and only if
$`\mathbb{E}_{\mu_n}[f] \to \mathbb{E}_{\bar\mu}[f]`$
for all continuous functions $`f:X\to\mathbb{R}`$.

Henceforth we will treat $`\Delta X`$ as a metric space
with such a metric.

**Lemma (compactness of space of probability measures)**:
Let $`X`$ be a compact metric space.
Then the set $`\Delta X`$ is compact.

**Definition (credal set)**:
Let $`X`$ be a compact metric space.
A credal set is a closed convex nonempty subset
of $`\Delta X`$.
The set of all credal sets over $`X`$ is denoted by
$`\Box X`$.

**Definition (Hausdorff distance)**:
Let $`X`$ be a compact metric space,
and $`\Theta_1,\Theta_2\in\Box X`$ be two credal sets.
Then the Hausdorff distance for these sets is defined by
$`d_H(\Theta_1,\Theta_2) := 
\max\{
\sup \{d(\theta_1,\Theta_2) | \theta_1\in\Theta_1\},
\sup \{d(\theta_2,\Theta_1) | \theta_2\in\Theta_2\}\}`$,
where $`d(\theta_i,\Theta_j) := 
\inf\{d(\theta_i,\theta_j) | \theta_j\in\Theta_j\}`$
is the distance of a point $`\theta_i`$ to a nonempty set $`\Theta_j`$.

**Lemma (credal sets as a metric space)**:
Let $`X`$ be a compact metric space.
Then the Hausdorff distance $`d_H`$ is a metric on $`\Box X`$.

**Lemma (destinies as a metric space)**:
Let $`h_1,h_2\in (A\times O)^\omega`$ be two destinies.
We define the distance function
$`d(h_1,h_2) := 2^{-t(h_1,h_2)}`$, where
$`t(h_1,h_2)`$ is the first index where $`h_1`$ and $`h_2`$
differ.
If $`h_1=h_2`$, we set $`d(h_1,h_2):=0`$.
Then $`(A\times O)^\omega`$ with the metric $`d`$
is a metric space.
The topology induced by that metric is the
product topology.

**Lemma (destinies as a compact space)**:
The set of destinies is a compact space.

**Definition (infrakernel)**:
Let $`X`$ be a compact metric space, and $`Y`$ be a topological space.
We call any function $`f : Y \to \Box X`$ an infrakernel.

**Definition (infrakernel generated by environments)**:
Let $`E`$ be a nonempty set of environments.
Then $`\Lambda_E:\Pi\to \Box ((A\times O)^\omega)`$
is defined as the function that maps
a policy $`\pi`$ to the closed convex hull of
$`\{\mu^\pi | \mu \in E\}`$.

**Definition (Crisp Causal Law)**:
A crisp causal law is an infrakernel 
$`\Lambda:\Pi\to \Box ((A\times O)^\omega)`$
generated by a nonemptty set of environments.


**Proposition 1 (infrakernel generated by environments is continuous)**:
Let $`E`$ be a nonempty set of environments.
Then $`\Lambda_E:\Pi\to \Box ((A\times O)^\omega)`$
is continuous.
The topology on $`\Pi = (A\times O)^*\to\Delta A`$
used for this purpose is the product topology,
based on the weak topology on $`\Delta A`$.


**Definition (expected loss wrt a crisp causal law)**:
Let $`L:(A\times O)^\omega\to[0,1]`$ be a continuous loss function.
The expected loss of a policy $`\pi`$ with respect to a crisp causal law
$`\Lambda:\Pi\to \Box ((A\times O)^\omega)`$
is defined by
```math
\mathbb E_{\Lambda(\pi)}[L] := \sup_{\theta \in \Lambda(\pi)} \mathbb E_\theta[L].
```

**Proposition 2 (continuity of expected loss)**:
Let $`L:(A\times O)^\omega\to[0,1]`$ be a continuous loss function
and $`\Lambda:\Pi\to \Box ((A\times O)^\omega)`$ be a crisp causal law.
Then the map 
$`\pi\mapsto \mathbb E_{\Lambda(\pi)}[L]`$ is continuous.

**Definition (Infra-regret)**:
Let $`L:(A\times O)^\omega\to[0,1]`$ be a continuous loss function.
The infra-regret of a policy $`\pi`$ with respect to a crisp causal law
$`\Lambda:\Pi\to \Box ((A\times O)^\omega)`$
is defined by
```math
\text{Reg}(\pi,\Lambda,L) :=
\mathbb{E}_{\Lambda(\pi)}[L] - 
\inf_{\pi'\in\Pi} \mathbb{E}_{\Lambda(\pi')}[L].
```


**Definition (Infra-Bayes optimal policy)**:
Let $`\zeta`$ be a probability distribution
over a countable class $`\{\Lambda_i\}_{i\in I}`$ of
infrakernels of type $`\Lambda_i:\Pi\to \Box ((A\times O)^\omega)`$.
We call $`\zeta`$ a prior (over infrakernels) in this context.
Let $`L:(A\times O)^\omega\to[0,1]`$ be a measurable loss function.
A policy $`\pi^*`$ is said to be Infra-Bayes optimal with respect to
$`\zeta`$ if it minimizes
$`\pi\mapsto\mathbb{E}_{\Lambda\sim\zeta}\left[\mathbb{E}_{\Lambda(\pi)}[L]\right]`$.

**Corollary 1 (existence of Infra-Bayes optimal policy)**:
Let $`\zeta`$ be a prior over crisp causal laws.
Let $`L:(A\times O)^\omega\to[0,1]`$ be a continuous loss function
and let $`A`$ be nonempty.
Then there exists an Infra-Bayes optimal policy.

**Definition (Non-anytime learnable)**:
Let $`L^\gamma:(A\times O)^\omega\to[0,1]`$ be a measurable loss function
for every $`\gamma\in[0,1)`$.
Let $`I`$ be an index set.
A class $`\{\Lambda_i\}_{i\in I}`$ of infrakernels
is said to be non-anytime learnable 
if there exists a family of policies 
$`\{\pi^\gamma\}_{\gamma\in[0,1)}`$ such that
$`\lim_{\gamma\nearrow 1} \text{Reg}(\pi^\gamma,\Lambda_i,L^\gamma) = 0`$
holds for all $`i\in I`$.
In that case, we say that 
$`\{\pi^\gamma\}_{\gamma\in[0,1)}`$ learns the class 
$`\{\Lambda_i\}_{i\in I}`$.

**Definition (non-dogmatic prior)**:
Let $`\zeta`$ be a probability distribution
over a countable class $`\{\Lambda_i\}_{i\in I}`$ of
infrakernels of type $`\Lambda_i:\Pi\to \Box ((A\times O)^\omega)`$.
We call $`\zeta`$ non-dogmatic prior if $`\zeta(\{\Lambda_i\})>0`$ for all $`i\in I`$.

**Proposition 3 (Infra-Bayes-optimal policy learns class)**:
Let $`\zeta`$ be a non-dogmatic prior
with respect to the countable class $`\{\Lambda_i\}_{i\in I}`$ of infrakernels.
If the class is non-anytime learnable,
then the family $`\{\pi^{*,\gamma}_\zeta\}_{\gamma\in[0,1)}`$
(where each $`\pi^{*,\gamma}_\zeta`$ is an Infra-Bayes-optimal policy for $`L^\gamma`$ and $`\zeta`$)
learns the class $`\{\Lambda_i\}_{i\in I}`$.



## Commentary and source material

The article roughly follows
"An Introduction to Credal Sets and Infra-Bayes Learnability"
from
https://www.lesswrong.com/s/n7qFxakSnxGuvmYAX/p/rkhaRnAc6dLzQT2sJ
until proposition 3.

There are some minor differences to the LessWrong article:
 - we also use the term infra-kernels for functions that are not necessarily continuous.
 - we do not use the TV metric, but a metric that is compatible with the weak topology.
 - credal sets have to be nonempty.
 - we use stochastic policies instead of deterministic ones, including in proposition 1.

We allow an arbitrary metric on $`\Delta X`$ 
(and this carries over to the Hausdorff metric on $`\Box X`$).
This is fine because the statements only really depend on the topology,
not any concrete metric.
